# second addition needs its own line, and --max-additions stays 0 for everything else.
#

# real, and it is a *Tcell* program (this is the Tcell gallery, so a dependency check is the difference
# between a curation and a guess). Say plainly if the request came from the author, because upstream's
# maintainers are the ones who will have to be comfortable with the entry.
